PRODUCT OVERVIEW

Architecture and integration

SGU-1 combines established concepts from OPL/ESFM, OPM, SID, POKEY and Paula in one programmable device: four-operator FM synthesis, flexible operator routing, per-channel subtractive filtering and hardware sweep units.

The module pairs a microcontroller with an audio CODEC. Together they generate a stereo 48 kHz I²S stream, converted by the CODEC to analog stereo line-level output. This provides the synthesis capabilities required by X65 without depending on advanced audio chips that are no longer manufactured.

The same C soft-core implementation runs in the SGU-Tracker and on the castellated hardware module. Host tools and target-side players may be adapted independently; the current C and 6502 players demonstrate two integration paths.

Engineering noticeElectrical limits, pin assignments and production specifications have not been released. Revision 1 data must not be used for production designs.

Key features

Synthesis engine

  • Nine channels with four operators per channel
  • Seven waveforms per operator, including sample playback
  • ESFM-style per-operator modulation and output routing
  • Waveform shaping and continuous signed pulse width
  • OPN-style AR / DR / SL / SR / RR envelopes

Modulation and control

  • Per-operator hard sync and ring modulation
  • Selectable LFO waveforms for AM and PM
  • Per-channel volume, frequency and cutoff sweeps
  • Per-channel phase-reset timer
  • Level-driven GATE and one-shot TRIG control

Audio path

  • Per-channel resonant low-pass, band-pass and high-pass filter
  • Stereo 48 kHz I²S output to audio CODEC
  • Analog stereo line-level output
  • 64 kB dedicated PCM sample memory

System integration

  • Castellated module for board-level integration
  • SPI host interface and USB-MIDI playback
  • SGM module format with C and 6502 playback software
  • Targets modern retro, vintage and embedded systems
