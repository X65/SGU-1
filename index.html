PRODUCT OVERVIEW

Features

  • Nine channels of four-operator FM synthesis
  • Stereo 48 kHz I²S audio path with analog line output
  • Eight operator waveforms: sine, triangle, sawtooth, pulse, noise, periodic noise, reserved and sample
  • Per-operator waveform shaping through WPAR
  • ESFM-style routing with independent output and modulation-input levels
  • Per-operator hard sync and ring modulation
  • OPN-style ADSR envelopes with sustain-rate control
  • Level-driven GATE plus one-shot TRIG retrigger and note-cut control
  • Per-channel resonant low-pass, band-pass and high-pass filtering
  • Continuous signed pulse width with 128 widths and two placements
  • Per-channel volume, frequency and cutoff sweep units
  • Per-channel phase-reset timer
  • Selectable saw, square, triangle and noise LFO shapes for AM and PM
  • 64 KiB dedicated PCM sample memory
  • Castellated module format for board-level integration
  • USB MIDI playback interface
  • 6502 player for SGM module format

Architecture and integration

SGU-1 is a new audio-synthesis device under development as part of the X65 Microcomputer Project. Its architecture combines established concepts from OPL/ESFM, OPM, SID, POKEY and Paula, including four-operator FM synthesis, flexible operator routing, per-channel subtractive filtering and hardware sweep units.

The device is implemented with a microcontroller and an audio CODEC. Together they produce a stereo 48 kHz I²S stream that the CODEC converts to an analog stereo line-level output. Developing a dedicated device provides the synthesis capabilities required by X65 without relying on advanced audio-synthesis chips that are no longer in production.

SGU-1 is intended for modern retro computers, original vintage machines, and modern embedded systems.

Host software and target-side playback may be adapted to the requirements of the system. sgu-tracker and the 6502 SGM player serve as the current development and proof-of-concept platform, demonstrating instrument definition, sequencing, effect control, module export, and playback as one possible integration path.

Prototype informationElectrical limits, pin assignments, and production specifications have not been released. Revision 1 data must not be used for production designs.
